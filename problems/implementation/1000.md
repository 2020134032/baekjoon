# 1000번: A+B

## 제한
- **시간 제한**: 2 초
- **메모리 제한**: 128 MB
- **제출**: 1413218
- **정답**: 551598
- **맞힌 사람**: 370887
- **정답 비율**: 38.365%

## 문제 설명
두 정수 A와 B를 입력받은 다음, A+B를 출력하는 프로그램을 작성하시오.

## 입력
첫째 줄에 A와 B가 주어진다. (0 < A, B < 10)

## 출력
첫째 줄에 A+B를 출력한다.

## 예제
### 예제 입력 1
```
1 2
```

### 예제 출력 1
```
3
```
