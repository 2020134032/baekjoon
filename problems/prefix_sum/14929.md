# 14929번: 귀찮아 (SIB)

## 제한
- **시간 제한**: 2 초 (추가 시간 없음)
- **메모리 제한**: 512 MB
- **제출**: 4618
- **정답**: 2111
- **맞힌 사람**: 1772
- **정답 비율**: 45.273%

## 문제 설명
\[\sum\_{1 \le a < b \le n}{x\_ax\_b}\]

## 입력
n과 xi가 주어짇나. n은 10만 이하ㅇ고, xi는 젗ㄹ댓값이 100이하인 정수디이다.

## 출력
위에서 구하란 걸 구하면 된ㄷ.

## 예제
### 예제 입력 1
```
3
1 -2 3
```

### 예제 출력 1
```
-5
```
