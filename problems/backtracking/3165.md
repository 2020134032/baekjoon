# 3165번: 5

## 제한
- **시간 제한**: 1 초
- **메모리 제한**: 128 MB
- **제출**: 1282
- **정답**: 299
- **맞힌 사람**: 224
- **정답 비율**: 24.806%

## 문제 설명
N과 K가 주어졌을 때, N보다 크면서 5가 적어도 K번 포함되는 가장 작은 수를 구하는 프로그램을 작성하시오.

## 입력
첫째 줄에 두 자연수 N과 K가 주어진다. (1 ≤ N ≤ 1015, 1 ≤ K ≤ 15)

## 출력
첫째 줄에 문제의 정답을 출력한다.

## 예제
### 예제 입력 1
```
99 1
```

### 예제 출력 1
```
105
```

### 예제 입력 2
```
595 2
```

### 예제 출력 2
```
655
```

### 예제 입력 3
```
123456789012345 3
```

### 예제 출력 3
```
123456789012355
```
